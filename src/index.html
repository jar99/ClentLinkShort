      How it works

      The URL is compressed with codes measured from real links — common characters cost a few bits, {{hostCount}} well-known hosts cost one byte, and any other domain's suffix (.com, .co.uk…) is a single symbol. Every legal encoding is priced and the shortest wins. The result goes after the # in the link, which browsers never send to servers — that one fact is the whole privacy model.

      Tracking parameters (utm_* and friends) are stripped first, unless you switch that off.

      Safety

      Any redirector can be dressed up as a trap, so this one is careful:

      • Only http and https open automatically. javascript: and data: links are refused outright.
      • Phishing-shaped links stop and show the destination first — paypal.com@evil.example, lookalike characters, bare IP addresses.
      • Every link carries a tamper check. A link that got clipped or edited says so instead of opening the wrong place. For proof of who made a link, sign it with a shared passphrase under advanced options.

      Limits

      • Short URLs stay shorter than any link to here. Below about {{breakEven}} characters, compressing doesn't pay for the domain.
      • Links can't be edited or revoked once shared — there's no server to tell.
      • No click counts and no expiry. Both need a server that remembers.

      Add ~ to the end of any Clent link to see where it goes without going there.

      Questions

      Do the links expire?
      No. The destination is inside the link itself, so there is nothing stored that could be deleted. A link keeps working as long as any copy of this page exists.
      What does the site see when a link is opened?
      Only that the page was requested. The destination rides in the URL fragment, which browsers never send to servers, so no server ever sees where a link points.
      Is it free?
      Yes. Free, open source under the MIT licence, no account, no ads, no tracking.
      Does it work offline?
      After the first visit, yes. The page keeps a copy of itself, and links decode in the browser without any network.
      What are the link styles?
      Standard uses only letters, digits, dash and underscore — it survives every chat app and clipboard. Dense packs the same link into fewer characters using URL punctuation, and Emoji spells it in emoji. All three open identically; pick Standard when unsure.

      No cookies, no localStorage, no analytics. Decoding a link takes one request, for this page itself — everything above runs in your browser.
